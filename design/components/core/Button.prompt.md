Tracked-caps CTA. Verb-first copy, trailing arrow that slides 3px on hover.

```jsx
<Button>Explore my work</Button>
<Button variant="secondary" showIcon={false}>About me</Button>
<Button variant="outline-gold">Let's build together</Button>
<Button variant="text" size="sm">Read article</Button>
```

Copy is uppercased by CSS — write it sentence case. Primary brightens on hover and gains a gold glow; it never scales.
